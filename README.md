# Evaluación Crediticia Automática - Banco Wiesse

Proyecto de Ciencia de Datos para predecir el riesgo de crédito usando Machine Learning.

## Objetivo
Desarrollar un sistema que ayude a los ejecutivos del banco a decidir si otorgan un préstamo, basado en historial de 3 años.

## Variables clave
- Clientes con >90 días sin pagar
- Préstamos vigentes
- Número de dependientes
